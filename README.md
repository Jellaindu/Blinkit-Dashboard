# Blinkit-Dashboard
🌱 My Power BI project on Blinkit — turning raw data into meaningful insights with visual storytelling.
Project Overview
The Blinkit Dashboard is an interactive Power BI project that visualizes Blinkit’s business performance.
It provides insights into total sales, outlet performance, item types, and customer ratings, helping to identify trends and make data-driven decisions.
🧩 Tools & Technologies
Power BI (for visualization and DAX calculations)
Excel / CSV Dataset (for data source)
Data Modeling and DAX Measures
📈 Key Insights
Total Sales: $1.20M
Average Rating: 3.9
Outlet Analysis by Size and Location
Item Type Breakdown (Top Performing Categories)
🎯 Skills Demonstrated
Data Cleaning & Transformation
DAX Functions & Calculations
Dashboard Design & Storytelling
Business Insights Generation
